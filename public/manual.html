인터넷 없이 · 공유기만으로

서명식 현장 운영 매뉴얼

태블릿에 받은 서명을 PC 화면에 실시간으로 띄우는 프로그램입니다. 행사장에 인터넷 회선이 없어도 공유기 하나만 있으면 동작합니다.

00 준비물 빠뜨리면 현장에서 못 구합니다

인터넷 회선(랜선을 벽에 꽂는 것)은 필요 없습니다. 공유기만 있으면 됩니다.

01 행사 전날 — 사무실에서 인터넷 필요 · 1회

  1. 1_준비.bat 더블클릭. 필요한 파일이 설치됩니다. 한 번만 하면 됩니다.
    Node.js가 없다고 나오면 nodejs.org에서 LTS 버전을 먼저 설치하세요.
  2. .env 파일을 메모장으로 열어 설정합니다.
    • ADMIN_PASSWORD — 관리자/모니터 비밀번호. 기본값에서 꼭 바꾸세요
    • TABLET_TOKEN — 태블릿 접속 토큰. 이것도 바꾸세요
    • TABLET_COUNT — 쓸 태블릿 대수 (기본 30)
    • BACKUP_DIR — 서명 사본이 쌓일 폴더. 예: C:/Users/user/Desktop/서명백업
  3. 폴더를 통째로 USB에 복사. node_modules 폴더가 같이 복사됐는지 확인하세요. 이게 없으면 현장에서 실행되지 않습니다.
  4. 태블릿 설정을 미리 해둡니다. 대수가 많으면 현장에서 할 시간이 없습니다.
    • 설정 → 디스플레이 → 화면 자동 꺼짐 → "없음"
    • 모바일 데이터 끄기
    • 화면 밝기 최대, 배터리 완충

화면 자동 꺼짐은 반드시 "없음"으로. 인터넷 없는 환경(http 주소)에서는 브라우저가 화면 꺼짐을 막을 수 없습니다. 프로그램이 보조 수단을 쓰긴 하지만 기기마다 효과가 다릅니다.

02 행사 당일 — 설치 약 15분

  1. 공유기 전원을 켭니다. 인터넷 선은 꽂지 않습니다.
    • 공유기가 2대라면 채널을 멀리 벌려두세요 — 하나는 36번, 다른 하나는 149번 근처. 채널폭은 80MHz
    • 두 공유기의 LAN 포트끼리 랜선 연결. 둘째 공유기는 DHCP 끄기
  2. 노트북을 공유기 LAN 포트에 랜선으로 연결합니다. 무선보다 안정적입니다.
  3. 2_시작.bat 더블클릭. 검은 창이 뜨고 브라우저가 자동으로 열립니다.
  4. 방화벽 창이 뜨면 "개인 네트워크" 허용을 누릅니다. 놓치면 태블릿만 접속이 안 됩니다.
  5. 검은 창의 이 PC 주소를 확인합니다. http://192.168.x.x:3000 형태여야 합니다. 브라우저 주소창도 같은 주소인지 보세요.
  6. 「📄 PDF로 받기」를 눌러 휴대폰에 저장합니다. 태블릿 1대당 1페이지짜리 QR 묶음입니다.
  7. 태블릿으로 QR을 스캔합니다. 번호 순서대로 하고, 태블릿 뒷면에 번호 스티커를 붙여두면 나중에 편합니다.
  8. 모니터링 화면에서 전부 초록불인지 확인합니다. 상단에 태블릿 번호와 접속 상태가 나옵니다.

주소가 localhost로 보이면 멈추세요. 그 상태로 만든 QR은 태블릿에서 절대 연결되지 않습니다. 검은 창의 이 PC 주소(192.168로 시작)로 다시 접속한 뒤 QR을 받으세요. 페이지 맨 위에 경고가 떠 있으면 바로 이 상황입니다.

03 운영 중

서명 받기

  1. 참가자가 태블릿에 서명합니다. 손바닥이 닿아도 먼저 닿은 손가락만 인식합니다.
  2. 「서명 완료 저장」을 누릅니다. 서명은 화면에 그대로 남습니다.
  3. 다음 사람이 그냥 그리기 시작하면 자동으로 지워집니다. 따로 지울 필요 없습니다.

와이파이가 순간 끊겨도 서명은 사라지지 않습니다. 태블릿 안에 보관됐다가 다시 연결되면 자동으로 전송됩니다. 화면에 「미전송 N건」이 뜨면 연결이 끊긴 상태입니다. 복구되면 저절로 사라집니다.

화면 둘러보기

QR 페이지 맨 위의 탭으로 바로 이동합니다.

크로마키로 송출하기

  1. 실시간 크로마키 편집으로 들어갑니다.
  2. 「접속된 것 모두 추가」로 태블릿을 무대에 올리고, 끌어서 위치와 크기를 맞춥니다.
  3. 「출력 모드」를 누르면 무대만 전체화면이 됩니다.
  4. P 키를 누르면 화면의 버튼과 마우스 커서가 사라집니다. 송출에 잡히지 않습니다. 다시 P를 누르면 나타납니다.

버튼을 숨겨도 무대 크기와 화면비는 바뀌지 않습니다. 크로마키 설정을 다시 잡을 필요가 없습니다. 숨긴 상태에서도 ESC로 출력 모드를 나올 수 있습니다.

칸 크기를 조정할 때는 송출 전에 미리 끝내두세요. 끄는 동안은 화면이 미리보기로 늘어났다가 손을 떼는 순간 선명해집니다.

04 행사 종료 후 서버 끄기 전에

서버를 끄기 전에 반드시 파일을 받으세요. 태블릿에 「미전송」이 남은 채로 서버를 끄면 그 서명은 올라가지 못합니다.

05 문제가 생겼을 때

증상원인과 조치
주소가 localhost이고
「연결할 수 없음」		QR이 잘못 만들어졌습니다. 검은 창의 이 PC 주소(192.168…)로 다시 접속해 QR을 받으세요
주소는 192.168인데
페이지가 안 열림		네트워크가 다릅니다. ①다른 공유기에 붙었는지 ②게스트 와이파이인지 ③공유기의 무선 격리가 켜져 있는지 확인하세요
페이지는 열리는데
「재연결 중…」		PC 방화벽입니다. 제어판 → 방화벽 → 앱 허용에서 Node.js를 개인 네트워크 허용
QR이 잘 안 찍힘QR 크기를 「아주 크게」로 바꾸거나, QR을 눌러 화면 가득 띄우세요. 휴대폰 PDF를 보여줘도 됩니다
태블릿이 「끊김」으로 표시35초 이상 반응이 없으면 끊김으로 봅니다. 화면을 켜면 자동으로 다시 붙습니다
태블릿 화면이 꺼짐OS 설정에서 화면 자동 꺼짐을 「없음」으로. 충전기를 꽂아두세요
「포트가 이미 사용 중」서버가 이미 켜져 있습니다. 검은 창을 하나만 남기세요
「node_modules 폴더 없음」USB 복사가 덜 됐습니다. 인터넷 되는 곳에서 1_준비.bat 실행
검은 창에 「네트워크 주소를
찾지 못했습니다」		노트북이 공유기에 연결되어 있지 않습니다. 랜선이나 와이파이를 확인하세요
서명이 늦게 뜸오프라인 구성에서는 드뭅니다. 태블릿이 2.4GHz에 붙었는지 확인하고 5GHz로 옮기세요

06 비상 대응

태블릿 1대만 안 될 때

  1. 브라우저를 새로고침
  2. 와이파이를 껐다 켜기
  3. 그래도 안 되면 예비 태블릿으로 교체. 같은 번호 QR을 스캔하면 그대로 이어집니다

전부 안 될 때

  1. 검은 창이 살아 있는지 확인
  2. 공유기 전원을 껐다 켜기 (IP가 바뀌면 QR을 다시 받아야 합니다)
  3. 노트북의 와이파이/랜선 연결 확인

노트북이 멈췄을 때

  1. 이미 저장된 서명은 디스크에 남아 있습니다. 날아가지 않습니다
  2. 재부팅 후 2_시작.bat 다시 실행
  3. IP가 그대로면 태블릿은 자동으로 다시 붙습니다
