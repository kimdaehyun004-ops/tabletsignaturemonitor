# 태블릿 서명 실시간 모니터링

태블릿(최대 10대 이상 확장 가능)에서 그리는 서명을 PC 화면에서 실시간으로 동시에 볼 수 있는 프로그램입니다.
기존 사이트와는 완전히 분리된 독립 프로젝트입니다.

- `public/sign.html` : 태블릿에서 여는 서명 화면 (펜/손가락으로 서명)
- `public/monitor.html` : PC에서 여는 실시간 모니터링 화면 (태블릿별 그리드로 동시에 표시)
- `public/links.html` : 태블릿 연결용 QR코드가 자동으로 나오는 페이지 (서버 실행하면 자동으로 열림)
- `server.js` : 두 화면을 실시간으로 이어주는 서버 (Node.js + WebSocket)

## 가장 빠른 사용법 (매번 이렇게만 하면 됩니다)

1. `tablet-signature-monitor` 폴더 안의 **`시작.bat`을 더블클릭** (Windows 기준)
   - 처음 실행이면 자동으로 필요한 설치가 진행됩니다 (몇십 초 소요)
   - 설치가 끝나면 서버가 켜지고, **브라우저가 자동으로 열리면서 QR코드 페이지(`links.html`)가 나타납니다**
2. QR코드 페이지에서 **각 태블릿 카메라로 해당 번호의 QR코드를 스캔** → 자동으로 서명 화면 연결 (번호/토큰 입력 필요 없음)
3. PC에서 QR코드 페이지 상단의 **"PC 모니터링 화면" QR코드를 스캔**하거나 링크 클릭 → 비밀번호(현재: **8450**) 입력하면 실시간 모니터링 시작
4. 작업이 끝나면 `시작.bat`을 실행했던 검은 창을 닫으면 서버가 꺼집니다

> 이 방법은 태블릿과 PC가 **같은 와이파이**에 연결되어 있어야 합니다 (IP 주소를 직접 입력할 필요는 없음, QR코드에 자동 포함). 같은 와이파이 없이 어디서든 접속하고 싶다면 아래 "온라인(어디서든) 접속되게 배포하기" 항목을 참고하세요.

---

## (참고) 수동 설치 방법

```
npm install
npm start
```

`.env` 파일에 아래 값이 이미 설정되어 있어 바로 사용할 수 있습니다 (다른 값으로 바꾸고 싶으면 `.env` 파일을 열어 수정하세요).

```
PORT=3000
ADMIN_PASSWORD=8450
TABLET_TOKEN=1234
TABLET_COUNT=10
```

- `ADMIN_PASSWORD` (현재: **8450**) : PC 모니터링 화면(`/monitor.html`) 접속 시 필요한 비밀번호
- `TABLET_TOKEN` (현재: **1234**) : 태블릿 화면(`/sign.html`) 접속 시 필요한 토큰 (모든 태블릿 공용)
- `TABLET_COUNT` : 사용할 태블릿 대수 (1번 ~ 이 숫자까지 번호가 만들어집니다)

> 다른 사람이 함부로 접속하지 못하게 하려면 나중에 `.env` 파일을 열어 원하는 값으로 바꾸면 됩니다.

## 온라인(어디서든) 접속되게 배포하기 - 같은 와이파이 없이도 사용하는 방법

지금까지 방식은 태블릿과 PC가 **같은 와이파이**에 있어야 했습니다. 아래처럼 클라우드에 한 번 올려두면, 그 다음부터는 태블릿과 PC가 서로 다른 장소·다른 통신망에 있어도 정해진 주소 하나로 접속할 수 있습니다. PC를 계속 켜둘 필요도 없어집니다.

### Render.com에 무료로 올리는 방법 (컴퓨터 명령어 없이, 웹사이트에서만 진행)

**1) GitHub에 코드 올리기**
1. https://github.com 에서 계정이 없다면 가입 (무료)
2. 로그인 후 우측 상단 `+` → **New repository** 클릭
3. Repository name에 `tablet-signature-monitor` 입력 → Public 또는 Private 선택 → **Create repository**
4. 생성된 페이지에서 **"uploading an existing file"** 링크 클릭
5. `tablet-signature-monitor` 폴더 안의 파일/폴더를 전부 끌어다 놓기 (단, `.env`, `node_modules`, `data` 폴더는 올리지 않아도 됩니다 — 없어도 정상 동작)
6. 아래 **Commit changes** 버튼 클릭해서 업로드 완료

**2) Render에 배포하기**
1. https://render.com 접속 → **Get Started** → GitHub 계정으로 로그인/가입
2. 대시보드에서 **New +** → **Web Service** 클릭
3. 방금 올린 `tablet-signature-monitor` 저장소 선택 → **Connect**
4. 설정 입력:
   - Name: 원하는 이름 (예: `youcan-sign`)
   - Region: Singapore (가장 가까운 지역)
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free** 선택
5. 아래 **Environment Variables** 항목에서 **Add Environment Variable**을 눌러 4개를 추가:
   - `ADMIN_PASSWORD` = `8450` (원하는 값으로 변경 가능)
   - `TABLET_TOKEN` = `1234` (원하는 값으로 변경 가능)
   - `TABLET_COUNT` = `10`
   - `PORT` 는 추가하지 않아도 됩니다 (Render가 자동으로 지정)
6. **Create Web Service** 클릭 → 몇 분 기다리면 배포 완료

**3) 완성된 주소 사용하기**
- 배포가 끝나면 화면 상단에 `https://youcan-sign.onrender.com` 같은 주소가 생깁니다
- 그 주소 뒤에 `/links.html`을 붙여서 접속하면 (`https://youcan-sign.onrender.com/links.html`) 태블릿용 QR코드가 자동으로 만들어집니다 — 로컬에서 하던 것과 완전히 동일하게 사용하면 됩니다
- 이제 태블릿과 PC는 각자 아무 와이파이/데이터망에서나 그 QR코드를 스캔하거나 주소로 접속하면 됩니다

> 무료 요금제는 일정 시간 접속이 없으면 서버가 잠들었다가, 다시 접속할 때 첫 로딩이 20~30초 정도 걸릴 수 있어요. 행사 시작 몇 분 전에 미리 한 번 접속해서 깨워두는 걸 추천합니다.

### 빠른 임시 테스트용: ngrok

당장 한 번만 테스트해보고 싶다면, PC에서 `npm start`로 서버를 켠 상태에서 [ngrok](https://ngrok.com)을 설치하고 `ngrok http 3000`을 실행하면 임시 공개 주소가 생깁니다. 다만 서버를 켤 때마다 주소가 바뀌고, PC가 꺼지면 접속이 끊깁니다 (지속적으로 쓰려면 위의 Render 방식을 추천합니다).

## 태블릿 설정 (QR코드 없이 수동으로 할 경우)

1. 태블릿 브라우저(크롬 등)에서 `https://<서버주소>/sign.html` 접속
2. 처음 접속 시 태블릿 번호(1~10)와 토큰(현재: **1234**)을 입력
3. 이후에는 브라우저에 저장되어 자동으로 재접속됩니다 (홈 화면에 바로가기 추가 추천)
4. 서명 후 "서명 완료 저장" 버튼을 누르면 서버에 이미지가 저장되고 화면이 자동으로 지워져 다음 서명을 받을 수 있습니다

번호/토큰을 URL로 바로 지정하고 싶다면:
`https://<서버주소>/sign.html?id=3&token=여기에토큰`

## PC 모니터링 설정

1. PC 브라우저에서 `https://<서버주소>/monitor.html` 접속
2. 비밀번호(현재: **8450**) 입력 후 입장
3. 태블릿 10대가 그리드로 표시되며, 각 태블릿에서 펜이 움직이는 대로 실시간으로 그림이 그려집니다
4. 온라인/오프라인 상태가 상단 점(초록/빨강)으로 표시됩니다
5. 오른쪽 "최근 완료된 서명" 패널에서 저장된 서명 이미지를 바로 확인/다운로드할 수 있습니다

## 저장된 서명 파일 위치

`data/signatures/` 폴더에 `tablet-{번호}_{시각}.png` 형식으로 저장됩니다.

## 보안 참고사항

- `.env`의 비밀번호/토큰은 반드시 기본값에서 변경한 뒤 사용하세요.
- 외부에 공개되는 주소로 운영할 경우 반드시 HTTPS를 사용하세요.
- 태블릿 토큰은 모든 태블릿이 공용으로 사용하는 간단한 방식입니다. 더 강한 보안이 필요하면 태블릿별로 서로 다른 토큰을 쓰도록 `server.js`를 확장할 수 있습니다.
- `links.html`(QR코드 페이지)은 편의를 위해 별도 비밀번호 없이 접속됩니다. 같은 와이파이 안의 누군가가 접속하면 태블릿 토큰이 노출될 수 있으니, 신뢰할 수 없는 네트워크에서는 사용을 피하세요.
